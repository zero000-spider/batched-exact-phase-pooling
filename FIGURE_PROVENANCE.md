# Experimental figure provenance

The check covers every experimental PNG/PDF pair shipped in `outputs/`, the five
source figures used by the Chinese manuscript, and the embedded media in all five
available Chinese manuscript versions. It verifies the data-to-figure workflow
by replaying plotting code and comparing the resulting files.

| Material | Check | Result |
| --- | --- | --- |
| 18 archived PNG figures | Redrawn from the recorded CSV tables; RGBA pixel arrays compared | All 18 pixel-identical |
| 18 archived PDF figures | Decoded page drawing streams compared with redraws | All 18 drawing-stream-identical |
| PDF contents | Inspect page resources and vector/text drawing operators | All 18 use vector/text plotting; zero embedded raster-image objects |
| Five manuscript source PNGs | Regenerated by `plot_results.py` from the recorded CSV tables | All five pixel-identical |
| Five Word manuscript versions, 25 embedded images | Embedded media SHA256 compared with the five source PNGs | All 25 matched their source figures |

The figures are reproducible Matplotlib plots of the recorded numerical results.
The synthetic-workload figures visualize explicitly identified computational
benchmarks. The per-file record contains input-table hashes, original/redrawn
image hashes, pixel-comparison results, PDF drawing-stream hashes and Word media
matches in `verification/figure_provenance.json`.

To repeat the checks' plotting stage, run `redraw_all_figures.py --check` for the archived
charts and `plot_results.py` for the manuscript charts. Manuscript PNGs are saved
before PDF exports to preserve the original PNG layout.

The conclusion is based on exact reproducibility and source tracing, rather than
a visual AI-image-classifier score. It establishes the numerical plotting origin
of the inspected files; it does not replace validation of the underlying datasets,
experimental protocol or scientific interpretation.
