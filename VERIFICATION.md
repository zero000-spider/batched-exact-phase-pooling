The classifier checks above are three fresh representative refits. The statistical
check reanalyzes the stored 224-configuration comparison; it does not retrain those
configurations. Other experiment commands are available in the README.

The adapter check loads the pinned upstream source unchanged. Its unused logistic
import is supplied by a sentinel that raises if invoked; its old ridge API call
uses a shim accepting `normalize=False` in the current scikit-learn environment.
The feature and prediction comparisons cover 32/64-point inputs at 9,408/49,728
features. This is a compatibility check in the reference environment; the full
method and results are recorded in `verification/adapter_equivalence.json`.

The portability review uses ASCII output directories and a noninteractive plotting
backend. Adapter-audit JIT caches are isolated from experiment caches so the README
commands can be run consecutively. Historical source fingerprints and the path
mapping are retained in `PATH_MIGRATION.json`; stored predictions and result
tables are preserved.

The per-file figure audit is summarized in `FIGURE_PROVENANCE.md` and recorded in
`verification/figure_provenance.json`. Archived figures are regenerated by
`redraw_all_figures.py`; manuscript figures are regenerated by `plot_results.py`.

The automatic Fish download returned HTTP 401 in the validation network. The
manual archive-import route in `DATA_SOURCES.md` was tested with the official
archive's recorded SHA256, followed by input reconstruction and classifier refits.
